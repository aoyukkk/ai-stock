==================================================
AI Trader Assistant Project Specification
Version: 1.2 Development Edition
==================================================


项目名称:
AI Trader Assistant


项目定位:

本项目是一套面向A股短线交易场景的AI智能交易辅助系统。

V1.2核心调整:

交易员倾向于盘前和盘后进行挂单，因此系统从“盘中高频推荐系统”升级为:

盘后生成次日交易计划
+
盘前重新评估挂单价
+
盘中低频监控与事件驱动风控
+
盘后复盘挂单质量

第一阶段目标:

AI辅助人工交易。

AI负责:

1. 全市场股票筛选
2. 信息收集
3. 多Agent分析
4. 股票评分排序
5. 推荐挂单价
6. 风险提醒
7. 撤单/改价提醒
8. AI模拟盘交易
9. 每日交易复盘
10. 挂单价质量评估
11. AI预测效果验证


人工负责:

1. 最终交易决策
2. 实盘买卖
3. 是否挂单
4. 是否撤单
5. 风险监督


未来扩展:

支持AI自动模拟交易。
长期验证后支持实盘自动交易。



==================================================
一、核心设计原则
==================================================


1. 模块化设计

所有模块必须独立。

禁止巨大单文件。
禁止混合业务逻辑。


2. 接口抽象化

禁止业务代码直接依赖:

- 同花顺
- DeepSeek
- OpenAI
- 数据库
- 交易接口

必须通过Adapter或Gateway。


3. 模型可替换

所有LLM调用必须经过:

LLM Gateway

禁止Agent直接调用模型API。


4. 数据源可替换

行情主数据源:

同花顺API

未来可替换:

- Wind
- Tushare
- JoinQuant
- 其他机构行情源

新闻数据源:

- 金十
- 同花顺资讯

未来可扩展:

- 财联社
- Reuters
- Bloomberg


5. 可验证性优先

系统必须保存:

- AI当时的预测
- AI当时使用的数据快照
- Prompt版本
- 模型版本
- 策略版本
- 挂单计划
- 挂单价候选
- 交易结果
- 挂单价复盘结果

目标:

未来能够回答:

“AI为什么在当时推荐这只股票？”

“AI为什么给出这个挂单价？”

“这个挂单价后来是否合理？”

“AI长期是否真的优于人工？”


6. 支持版本迭代

代码必须:

- 可测试
- 可回滚
- 可扩展
- 可回测

==================================================
十一、挂单价评估模块
==================================================


模块名称:

Order Price Evaluation Engine


定位:

给出可执行的盘前/盘后挂单计划。

原则:

挂单价格由量化规则和行情数据计算。
LLM只负责解释、审核和风险判断。
禁止LLM凭感觉直接生成价格。


输出:

- 保守买入价
- 平衡买入价
- 激进买入价
- 推荐挂单价
- 最高可接受买入价
- 止损价
- 第一止盈价
- 第二止盈价
- 建议仓位
- 挂单有效条件
- 撤单条件
- 是否允许追价
- 挂单置信度


核心数据:

- 昨日收盘价
- 昨日最高价
- 昨日最低价
- 近5日高低点
- 近20日高低点
- MA5
- MA20
- VWAP
- ATR
- 成交量
- 换手率
- 支撑位
- 压力位
- 涨跌停价
- 新闻评分
- 情绪评分
- 资金评分
- 集合竞价数据，如可获取


核心公式:


1. TR真实波动幅度:

TR = max(
  High - Low,
  abs(High - Previous_Close),
  abs(Low - Previous_Close)
)


2. ATR:

ATR_N = Average(TR, N)

默认:

N = 14


3. 回踩买入价:

Buy_Pullback = Support + 0.05 × ATR


4. 平衡买入价:

Buy_Balanced =
0.5 × Support
+
0.3 × VWAP
+
0.2 × Previous_Close
+
Adjustment


Adjustment:

利好新闻或强情绪:

+0.1 × ATR

风险升高:

-0.1 × ATR


5. 突破买入价:

Buy_Breakout = Resistance + Tick_Size


6. 最高可接受买入价:

Max_Buy_Price = min(
  Limit_Up_Price,
  Previous_Close + 0.8 × ATR,
  Previous_Close × (1 + Max_Chase_Percent)
)


7. 止损价:

Stop_Loss = max(
  Entry_Price - 1.0 × ATR,
  Entry_Price × (1 - Max_Stop_Loss_Percent)
)


说明:

对买入价而言，止损价越接近买入价，风险越严格。
这里取更严格的较高止损价。


8. 第一止盈价:

Take_Profit_1 = Entry_Price + 1.0 × ATR


9. 第二止盈价:

Take_Profit_2 = Entry_Price + 2.0 × ATR


10. 压力位卖出价:

Sell_Resistance = Resistance - Tick_Size



==================================================
十二、挂单价评分
==================================================


每个候选挂单价必须输出评分。

Order Price Score =

0.35 × Expected_Return_Score

+

0.25 × Fill_Probability

+

0.20 × Risk_Reward_Score

+

0.10 × Emotion_Score

+

0.10 × Capital_Confirmation_Score



风险收益比:

Risk_Reward =

(Target_Price - Entry_Price)

/

(Entry_Price - Stop_Loss_Price)



默认要求:

Risk_Reward >= 1.5


理想:

Risk_Reward >= 2.0



三档价格:

1. Conservative

保守价，偏低吸，成交概率低，但安全边际高。


2. Balanced

平衡价，系统默认推荐价。


3. Aggressive

激进价，成交概率高，但追高风险更大。



==================================================
十三、风险否决机制
==================================================


Risk Agent具有最高优先级。

以下情况即使综合评分高，也不得进入推荐池或不得生成买入挂单:

1. 重大监管处罚
2. 财务造假风险
3. 重大事故
4. 停牌或即将停牌
5. 流动性严重不足
6. 连续异常上涨且换手过高
7. 重大负面公告
8. 无法成交风险过高
9. 盘前高开过大
10. 竞价异常且无法确认承接


输出状态:

- ALLOW
- WATCH_ONLY
- CANCEL_ORDER
- REPRICE
- BLOCK

==================================================
十七、成本控制
==================================================


系统必须有LLM Cost Controller。


原则:

DeepSeek V4 Flash处理普通任务。

GPT-5.5只处理高价值任务:

- Risk Agent
- Controller Agent
- 黑天鹅分析
- 高分股票最终审核
- 挂单计划最终审核
- 每日复盘


盘中普通刷新延长后，整体Token成本应低于V1.1。


GPT调用策略:

只有满足以下条件之一才调用GPT-5.5:

1. 股票进入Top50深度分析
2. 风险不确定
3. 出现黑天鹅事件
4. 最终评分较高
5. 交易影响较大
6. 挂单计划需要最终审核
7. 每日复盘


必须记录:

- input_tokens
- output_tokens
- cached_input_tokens
- cost_usd
- latency_ms
- provider
- model_name
