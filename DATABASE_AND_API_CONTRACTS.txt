AI Trader Assistant 数据库与 API 契约
Version: V0.3
============================================================

一、数据库技术
------------------------------------------------------------
主数据库：PostgreSQL
缓存：Redis
向量：Chroma
图谱：Neo4j optional，默认关闭
离线分析：DuckDB/Parquet optional

原则：
1. AI建议必须可追溯。
2. 模型调用必须记录成本。
3. 交易计划必须可复盘。
4. 配置修改必须可回滚。
5. 重要 JSON 使用 JSONB。
6. 高频查询必须建索引。

三、API 契约
------------------------------------------------------------

  "success": true,
  "data": {},
  "error": null,
  "trace_id": "string"
