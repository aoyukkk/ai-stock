AI Trader Assistant Codex 分模块开发提示词
Version: V0.3
============================================================

重要规则
------------------------------------------------------------
Codex 在执行任何阶段前必须阅读：
1. PROJECT_SPECIFICATION.txt
2. SYSTEM_CONFIG_DESIGN.txt
3. DATABASE_AND_API_CONTRACTS.txt
4. 当前阶段相关文档

硬性要求：
1. 不要一次重写整个项目。
2. 只修改当前阶段相关文件。
3. 不要删除已有测试。
4. 不要硬编码配置。
5. 外部数据源必须使用 Adapter。
6. 模型调用必须经过 LLM Gateway。
7. 挂单价必须由规则模块计算。
8. LLM 只能解释/审核/风控挂单价。
9. 所有 AI 建议必须保存 prediction_record 和 decision_snapshot。
10. 每阶段完成后必须运行测试并输出开发报告。

开发报告格式：
Phase:
Completed:
Files changed:
Features:
Tests:
Problems:
Known limitations:
Next step:
Suggested git commit message:
