十一、配置加载规则
------------------------------------------------------------
ConfigService.get(key):
1. 先查 runtime override。
2. 再查数据库 active config。
3. 再查 YAML。
4. 再查 code default。

ConfigService.update(key, value, user, reason):
1. 校验 schema。
2. 校验权重和等业务规则。
3. 写 active config。
4. 写 config_history。
5. 通知订阅模块。
6. 前端显示生效。

十二、内部 Web 共享登录
------------------------------------------------------------
APP_RUNTIME_MODE=INTERNAL_WEB_SERVER
AUTH_MODE=LOCAL_SHARED_PASSWORD
SHARED_LOGIN_USERNAME=partners
APP_ORIGIN_HOST=127.0.0.1
APP_ORIGIN_PORT=8080

共享密码不得写入环境文件。必须通过 ai-trader-internal-web.exe 的
set-shared-password 管理命令交互输入，数据库只保存 Argon2id Hash。
共享主体固定为 ADMIN；审计记录无法区分四名合伙人中的具体操作者。
