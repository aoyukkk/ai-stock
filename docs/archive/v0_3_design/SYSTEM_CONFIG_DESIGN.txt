AI Trader Assistant 系统配置设计
Version: V0.3
============================================================

一、设计原则
------------------------------------------------------------
所有影响系统运行的参数必须配置化。
禁止硬编码。

配置来源优先级：
1. Web UI Runtime Config
2. Database Config
3. Config File YAML
4. Code Default

含义：
- Web UI 修改后立即生效，并写入数据库。
- YAML 作为初始默认值和版本化配置。
- Default 只作为兜底，不应依赖。
- 所有修改都必须写入 config_history。
