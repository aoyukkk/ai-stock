============================================================

一、全局测试命令
------------------------------------------------------------

python -m pytest
python -m pytest tests/test_health.py
python -m pytest tests/test_config_service.py
python -m pytest tests/test_quant_engine.py
python -m pytest tests/test_order_price.py
python -m pytest tests/test_virtual_broker.py

npm run test
npm run build

python scripts/run_mock_day.py
python scripts/run_post_market_workflow.py
python scripts/run_pre_market_recheck.py
python scripts/run_daily_review.py

[ ] 跌停卖出可能失败。
[ ] 支持部分成交。
[ ] 支持撤单。
[ ] 支持改价。

[ ] 卖出印花税计算正确。

十六、端到端验收
------------------------------------------------------------
Mock Day 流程：
1. 导入 mock 股票和行情。
2. 运行盘后计划。
3. 生成 order_plan。
4. 运行盘前复核。
5. 模拟盘中价格波动。
6. VirtualBroker 执行虚拟挂单。
7. 记录人工交易。
8. 运行每日复盘。
9. 生成 reflection memory。
