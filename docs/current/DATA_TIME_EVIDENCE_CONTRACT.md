# Data Time and Evidence Contract

- BaselineClose必须来自ranking_trade_date正式收盘缓存。
- D1/D3/D5/D10使用项目交易日历，不使用自然日。
- FutureClose仅在目标交易日已经成熟时读取。
- 停牌不顺延；缺失不以前收盘价填充；未来收益不填0。
- 固定验收最大行情日期为2026-07-30。
- 全量行情按交易日批量读取，禁止逐股Provider调用。
- `RAW_CLOSE_SIGNAL_RETURN` 与可执行收益不得混算。
- 行业、市值、流动性诊断必须使用推荐日当时可用字段。
- V3.1真实事件搜索的决策时点和实际执行时间都必须早于目标交易日09:25；截止后禁止通过回填较早时间重新搜索。
- 市场新闻、普通公司事件、Tier 1正式公告的最大年龄分别为36、72、168小时。
- 未来证据、未知发布时间、缺少原始URL、过期、重复转载或非法数值证据只保留审计，不参与评分。
- 无合格事件证据时事件贡献固定为0，V3.1分必须严格等于Quant分；搜索失败不得转换为“无消息”。
