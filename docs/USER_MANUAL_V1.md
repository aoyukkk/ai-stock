# AI Trader Assistant 1.0.0 用户手册

## 产品定位

AI Trader Assistant 是面向 A 股日度筛选的交易辅助工作台。它用于数据检查、量化排名、LLM 二筛、人工股票池、最终排序、挂单价与仓位建议、历史绩效和 Excel 复盘。最终交易决定始终由用户作出，程序不执行实盘或虚拟盘下单。

## 日常流程

1. 在“数据状态”确认目标交易日和数据水位。
2. 配置 Tushare Token 后执行数据更新，再运行全 A 量化。量化阶段不调用 LLM。
3. 配置 DeepSeek API Key，查看预算并确认后运行 LLM 二筛。
4. 在“人工选股”添加或调整关注股票。人工选择不会修改模型原始评分。
5. 确认预算后生成最终排序、挂单价、仓位和重点基本面摘要。
6. 导出 Excel，并在“选股收益统计”查看后续市场表现。

任务在数据库中持久化。页面刷新后可从“运行记录”查看状态；失败或取消的支持任务可从断点恢复。重复提交会复用正在执行或已成功的同参数任务。

## 历史数据

首次安装会导入脱敏历史样本，至少包含 2026-07-10。未配置任何密钥时仍可离线查看这些结果。历史结果的数据来源显示为 `DATABASE`，不会用 Mock 结果冒充真实运行。

## 设置与密钥

桌面版密钥由 Electron `safeStorage` 加密，保存在当前 Windows 用户的数据目录。页面和后端 API 不提供密钥原文回读。删除密钥后，对应真实任务立即不可用。

所有真实 LLM 任务都需要用户点击并确认预算。真实交易、调度器、虚拟交易和自动下单始终默认关闭。

## 数据位置

程序数据位于 Electron 的用户数据目录，包含 `data`、`cache`、`outputs`、`logs`、`backups`、`config` 和 `diagnostics`。卸载程序默认保留这些数据。Excel 位于 `outputs` 下按交易日组织的目录中。
