# AI Trader Assistant 1.0.0 故障排查

## 程序无法启动

在启动失败对话框中选择“打开日志目录”，先查看 `electron.log` 和 `backend.log`。确认安全软件没有隔离 `ai_trader_backend.exe`，并确认用户数据目录可写。

## 后端启动超时

首次启动会复制 Seed、检查 SQLite 并创建备份，耗时可能较长。等待后重试一次。持续失败时记录日志中的错误类型，不要发送密钥文件或完整数据库。

## 历史结果不可见

检查工作台日期列表中是否有 2026-07-10，并确认来源为 `DATABASE`。如数据库已存在，程序不会覆盖它或重复导入 Seed。可先备份用户数据，再由后续维护工具执行历史样本重导入。

## Token 或 API Key 测试失败

重新输入密钥，检查网络、防火墙、代理和账户权限。密钥不会显示原文。Tushare 用于数据与量化，DeepSeek 用于明确确认预算后的 Flash 和 Pro 阶段。

## 任务失败或中断

在“运行记录”查看阶段、错误码和进度。失败、取消或部分成功的任务可恢复；不要反复创建同一任务。Quant 被时间一致性门禁阻断时，应先补齐目标交易日数据。

## Excel 无法导出

确认用户数据目录和 Excel 输出目录可写，并关闭正在占用同名文件的 Excel。程序会为重名文件生成带时间戳的新文件。

## 安全信息

诊断时不要发送 `secrets.enc.json`、`.env`、API Key、Token 或账号密码。真实交易、调度器、虚拟交易和自动下单在 1.0.0 中保持关闭。
