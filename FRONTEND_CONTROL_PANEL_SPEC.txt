AI Trader Assistant 前端控制台规格
Version: V0.3
============================================================

一、前端技术栈
------------------------------------------------------------
推荐：
- Vue3
- TypeScript
- Element Plus
- Pinia
- ECharts
- Axios
- WebSocket
- Electron 桌面壳

理由：
- 控制台表单复杂，Vue + Element Plus 更适合。
- 交易计划表、配置表、模型管理、复盘页都可以快速开发。
- Electron 可打包 Windows 桌面应用。

------------------------------------------------------------

四、System Config 页面
------------------------------------------------------------
必须全部可视化显示并可编辑。

A. 股票筛选配置
- quant_top_n Q：数字输入，默认 500
- light_analysis_top_n L：数字输入，默认 500
- committee_analysis_top_n N：数字输入，默认 50
- final_recommend_top_n R：数字输入，默认 50
- manual_watchlist_default W：数字输入，默认 50
- manual_watchlist_soft_warning：默认 100
- 是否启用人工池硬限制：开关，默认关闭
- 是否允许盘中新股动态入池：开关，默认关闭
- 每日最大动态入池数量：数字输入

B. 刷新频率配置
- 全A轻量量化雷达：启用/关闭，分钟输入
- 推荐池刷新：分钟输入
- 人工关注池刷新：分钟输入
- 持仓刷新：分钟输入
- 挂单刷新：分钟输入
- 新闻刷新：分钟输入
- 开盘/尾盘高频刷新：启用/关闭，分钟输入

C. 因子权重配置
- technical
- capital
- emotion
- momentum
- risk
要求：前端校验权重和 = 1。

D. AI评分权重配置
- technical
- capital
- news
- emotion
- overseas
- risk
要求：前端校验权重和 = 1。

E. 挂单价配置
- ATR window
- tick size
- max chase percent
- min risk reward
- ideal risk reward
- max stop loss percent
- default position percent
- conservative support buffer
- balanced support/vwap/previous close weights
- aggressive breakout tick buffer
- stop loss ATR multiplier
- take profit ATR multipliers
- order score weights
- cancel condition thresholds
- reprice condition thresholds

F. 风控配置
- 仓位上限模式：disabled / advisory_only / hard_block
- 单股最大仓位百分比
- 行业最大仓位百分比
- 是否阻断 ST
- 是否阻断停牌
- 是否阻断重大负面新闻
- 是否阻断黑天鹅
- 高开过大是否禁止挂单
- 止损默认百分比
- 最大回撤预警

G. 事件触发配置
- 快速上涨阈值
- 快速下跌阈值
- 成交量异常倍数
- 换手异常倍数
- 新闻重要性阈值
- 重大负面阈值
- 高开撤单阈值
- 低开复核阈值
- 接近成交阈值
- 改价偏离阈值
- Emergency Mode cooldown

H. 虚拟盘配置
- 是否启用
- 初始资金
- 手续费率
- 最低佣金
- 卖出印花税
- 滑点率
- 是否允许部分成交
- 是否支持撤单
- 是否支持改价
- 是否模拟涨停买不进
- 是否模拟跌停卖不出

I. 记忆配置
- 短期记忆开关
- 中期记忆开关
- 向量记忆开关
- 长期记忆开关
- 图谱记忆开关
- top_k
- min_reuse_score
- 是否过滤冲突记忆
- 低质量记忆过期天数

J. 成本预算
- 每日 token 预算
- warning 百分比
- hard limit 百分比
- GPT-5.5 日预算
- DeepSeek 日预算
- 缓存开关
- 缓存时间

所有配置修改弹窗必须要求填写：
- 修改原因
- 是否立即生效
- 是否保存为默认

保存后：
- PUT /api/config/{key}
- 写 config_history
- 显示旧值、新值、修改人、时间
