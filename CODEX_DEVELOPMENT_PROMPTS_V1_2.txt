==================================================
GENERAL CODEX DEVELOPMENT RULES
==================================================


You are the lead software engineer.

Your goal:

Build a production-quality AI trading assistant for A-share short-term trading.

Follow these rules:


RULE 1:
Modular development only.

Never create:

- huge single files
- mixed business logic
- hard-coded configuration


RULE 2:
All external services must use adapters.

Bad:

Agent → ths_api.py

Good:

Agent → Data Interface → THS Adapter


RULE 3:
All AI models must use LLM Gateway.

Forbidden:

agent.py directly calls OpenAI or DeepSeek.

Allowed:

agent.py calls llm.chat()


RULE 4:
All configuration must be stored in:

config/

or

.env

or

database configuration table.


RULE 5:
Every module requires:

- unit test
- error handling
- logging


RULE 6:
Maintain backward compatibility.


RULE 7:
Do not remove existing tests.


RULE 8:
Do not hard-code model names inside Agents.

Use model config.


RULE 9:
Do not hard-code stock selection numbers.

Use config:

quant_top_n
light_analysis_top_n
committee_analysis_top_n
final_recommend_top_n
manual_watchlist_limit


RULE 10:
All AI recommendations must be traceable.

Save:

- prediction_record
- decision_snapshot
- model_version
- prompt_version


RULE 11:
Order prices must be calculated by rule-based modules.

LLM can explain and review order prices.

LLM must not invent order prices without market data.


RULE 12:
Every order plan must be reviewable.

Save:

- order_plan
- order_price_candidate
- order_plan_evaluation
- order_reassessment_log

PHASE 5
Order Price Evaluation Engine
==================================================

Goal:

Create rule-based order price evaluation module.


Implement:

order_price/atr_model.py

order_price/support_resistance.py

order_price/price_level_calculator.py

order_price/execution_probability.py

order_price/order_score.py

order_price/order_plan_generator.py


Core formulas:

TR = max(
  High - Low,
  abs(High - Previous_Close),
  abs(Low - Previous_Close)
)

ATR_N = Average(TR, N)

Buy_Pullback = Support + 0.05 × ATR

Buy_Balanced =
0.5 × Support
+
0.3 × VWAP
+
0.2 × Previous_Close
+
Adjustment

Buy_Breakout = Resistance + Tick_Size

Max_Buy_Price = min(
  Limit_Up_Price,
  Previous_Close + 0.8 × ATR,
  Previous_Close × (1 + Max_Chase_Percent)
)

Stop_Loss = max(
  Entry_Price - 1.0 × ATR,
  Entry_Price × (1 - Max_Stop_Loss_Percent)
)

Take_Profit_1 = Entry_Price + 1.0 × ATR

Take_Profit_2 = Entry_Price + 2.0 × ATR


Output:

- conservative price
- balanced price
- aggressive price
- recommended price
- max acceptable price
- stop loss price
- take profit prices
- risk reward
- fill probability
- order price score
- cancel conditions
- reprice conditions


Testing:

- Generate three price candidates from mock OHLCV data
- Verify risk_reward >= configured minimum
- Verify max buy price does not exceed limit up price
- Verify output saved to order_plan and order_price_candidate
